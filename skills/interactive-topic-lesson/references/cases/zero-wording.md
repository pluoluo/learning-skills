# 反例说明：“平均3，但甲0”的题面歧义

来源：用户报告家长两次将原话读成“每人3块，这题不可能”；以下是修订推演，未声称新题已通过真实孩子试用。

## 原设计与失效

题面：“四人平均3块，但甲一块也没有。”数学上可以存在0、4、4、4，但“平均3”被读成“已经平均分给每人3”。另版“构造反例，丁至少9块”没有说清要回应哪句话，又增加未解释术语和不必要的大差异。schema和浏览器无法发现这些误解。

## P0-2三问如何识别与哪里不够

这个任务允许答错吗：如果要在总数12且甲0下构造，其余给4、4、4合法，给3、3、3不合法；若只要求固定12块下“平均3”，仍是自动成立的演示。须先把真正要回应的判断写清。

最薄弱任务：“甲0”可能把注意力从平均与实际分法引向“题目是不是矛盾”；“丁9/反例”则可能靠试错满足数字，却不知道要说明什么。问题不是单纯加深算术。

学后新能力与实际机会：用一个自然分法回应“人人数量必相同”的断言。活动须允许摆法加解释，不能只让孩子处理难懂题面。

三问能暴露目标与产出不清，但不能保证作者发现措辞歧义；必须加P0-1无设计上下文冷读。把预期意思解释给读者再问“懂了吗”无效。

## 冷读修订方案

不再把“平均3”和“甲0”压在同一句里；先明说桌上共有8块、要分给四人，再引用小明的断言：“不管怎么分，每个人都会有2块。”请摆一种分法说明它有时不对。1、2、2、3已足够，不必制造0或9。讲解再说明把所有饼干合起来平均分的意义。

冷读须逐字保留完整题面、指令和按钮，问“我要做什么、做完看到什么”，逐条记录“平均分=实际已分好”“每个人都不能2块”等潜在误读及改句。这里列的是已知风险，不能冒充未做的冷读结果。数值8/4=2可独立验算；表达清晰和实际学习效果另验。
