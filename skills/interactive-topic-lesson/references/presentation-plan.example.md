# 呈现计划：用实际分法回应一句话

修订号：P3；依据教学计划T3

## 场景与信息

四个人物下方显示饼干及各自数量，初始2、2、2、2；总数8可见。每人下方的拿/给按钮可点按或键盘操作。手中未放回时检查不可用。平均分的演示按需打开，不自动高亮解法或填预测。1000×600宿主中优先显示题面、操作与结论，长解释可滚动；1920×1080扩大学习对象。

学生可见题面原文：桌上有8块饼干，要分给四个人。小明说：“不管怎么分，每个人都会有2块。”你能摆出一种分法，说明他这句话有时不对吗？用完8块后点“检查分法”，再在下面写一句：你的分法哪里和小明说的不一样？

其他可见文字：“饼干总数（含手中）：8块”“我手中：0块”“从这里拿1块”“给这里1块”“检查分法”“写一句：你的分法哪里和小明说的不一样？”“保存解释”“看看分法提示（可选）”“恢复四人各2块（保留已存作品和解释）”。操作提示：“先从一个人那里拿，再给另一个人；手中有几块就可以分几次给。”“把手中的饼干都给出去，再检查分法。”手中0块时给按钮不可用。新例题面：“桌上有6块饼干，要分给三个人。小明说：‘不管怎么分，每个人都会有2块。’你能摆出一种分法，说明他这句话有时不对吗？用完6块后点‘检查分法’，再在下面写一句：你的分法哪里和小明说的不一样？”初始三人各2块，同样操作；总数6，恢复按钮“三人各2块”。

## 反馈、帮助与作品

错误文字：“分法还没答对。现在人人2块，还不能说明小明这句话有时不对。可以试着把1块从一个人那里移给另一个人。”正确文字：“分法答对了。总数是8，你摆的分法不是人人2块。解释还要请家长看看。”解释文字：“解释已保存，待家长查看。这页不会自动判断解释对错，也不会通知家长；可以现在请家长一起看，或保存本次记录后再看。你可以继续改，也可以结束。”解释可随时保存。invalid显示“还不能判断”，保存失败保留输入。提示展示移1块的方法，使用后如实记录；恢复不删旧作品。以上结果分首行结论和后续解释显示。

逐条理解偏差与修改：第一轮读者认为“他们现在肯定每人2块”与初始人人2块冲突→改成“不管怎么分”；“不一定每人”易读成每个人都不能2块→改成引用断言并找一次不符；“拿/给”对象不清→每人下按钮改“从这里/给这里”；“说说”像口头说→明确“在下面写一句”。第二轮读者说“没有看到题意矛盾”，但仍不清楚作品怎样保存、恢复是否删未存文字、家长查看是否必须。P3保留这些待修项，不能直接进实现。
