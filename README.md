# Learning Skills

把孩子正在遇到的学习困难，变成一节可以动手探索的小课。

这里提供可安装到 AI Agent 中的学习 Skill。你用自己的话描述一个问题，Agent 就能据此制作互动课程，让孩子通过操作、比较、尝试和反馈理解知识，再换一个例子看看能不能用上。

目前提供 **[互动专题小课 · interactive-topic-lesson](skills/interactive-topic-lesson/SKILL.md)**。

![周长与面积互动小课预览](https://github.com/pluoluo/learning-skills/releases/download/v0.1.1/perimeter-area-preview.png)

## 它能帮你解决什么问题？

有时，孩子已经听过讲解，也记住了公式，遇到具体问题却仍然不知道怎么用。继续重复同一段解释，很难看出究竟卡在哪里。

这个 Skill 帮助家长和教育创作者围绕具体困难制作学习活动：

- **概念容易混淆**：例如分不清周长与面积，让孩子改变图形，分别观察边界长度和覆盖大小。
- **规则会背，换个情境就不会用**：例如知道近义词释义，却不会在句子中选择，便通过替换、比较和寻找语境依据来探索。
- **现成材料不贴合眼前的问题**：可以说明孩子已会什么、哪里停住、希望重点观察什么，据此制作范围合适的小课。
- **想让孩子主动尝试**：课程包含能改变对象或判断的操作，以及解释原因的反馈、按需提示和重试机会。

可以围绕数学、语文、英语中的具体问题创作。你不必先写完整教案，也不必准备一套教材；一个清楚的困惑就可以作为起点。

## 先体验一节小课

**[下载「周长与面积」互动样例](https://github.com/pluoluo/learning-skills/releases/download/v0.1.1/perimeter-area-demo-v0.1.1.zip)**，解压后用浏览器打开 `index.html` 即可。体验样例无需安装开发工具、注册账号或配置模型。

在这节课里，孩子可以：

1. 改变长方形的长与宽，切换观察“围一圈”和“铺满”。
2. 用同样长的围栏围出不同形状，比较草地面积。
3. 随时查看提示、回到探索，再用新例子核对自己的发现。

你也可以先看看 **[Skill 的完整说明](skills/interactive-topic-lesson/SKILL.md)**，了解它如何组织一节课。

## 用它制作你的小课

创作新课程需要一个支持 Agent Skills、能够读写文件和运行脚本的 AI Agent，以及 Node.js 20 或更高版本。模型由你使用的 Agent 提供；生成后的课程可以独立在浏览器中打开。

1. **[下载完整 Skill](https://github.com/pluoluo/learning-skills/releases/download/v0.1.1/interactive-topic-lesson-v0.1.1.zip)**，解压并保留整个 `interactive-topic-lesson` 文件夹。
2. 按你的 Agent 的安装方式，将该文件夹放入技能目录。Hermes 用户可放到 `~/.hermes/skills/interactive-topic-lesson`，在新会话中使用 `/interactive-topic-lesson`。
3. 告诉 Agent 想解决什么问题，以及课程保存到哪里。

例如：

> 使用 interactive-topic-lesson，给四年级孩子做一节周长与面积的小课。他会套公式，但经常分不清题目问的是哪一种量。希望能通过改变图形发现区别，最后换个例子试试。请把课程保存到一个新文件夹。

也可以从一个好奇的问题开始：

> 使用 interactive-topic-lesson，做一个分数比较小课：同样大小的纸条，为什么 1/2 比 1/3 大？希望孩子通过等分和比较发现原因，并且可以随时看提示、重新尝试。

如果有错题、教材片段或自己的观察，可以一起提供。生成后也可以继续提出修改要求，例如“解释再短一点”“增加一个反例”或“把拖动改成点选”。

## 你会得到什么？

最主要的成果是一个 **`index.html` 互动课程文件**。用浏览器打开，就能让孩子操作、查看反馈并完成本次练习。

同时会保留可编辑的课程内容，方便继续调整、重新生成或交给学习应用使用。课程不依赖本项目的学习平台账号，当前独立版的操作和选择保留在本次页面中。

AI 生成后，建议先亲自操作一遍，核对知识、图示和答案是否符合预期。孩子在一节课里的表现，可以帮助你发现下一步值得继续探索的问题。

## 持续更新

我会持续维护这个项目，根据真实使用反馈改进教学设计、操作体验和生成质量，补充更丰富的学科样例，并逐步分享更多实用的学习 Skill。

如果你遇到不好理解的反馈、无法操作的内容，或某个学习问题始终没有被解决，欢迎通过 **[Issues](https://github.com/pluoluo/learning-skills/issues)** 告诉我。描述你想解决的问题、实际发生了什么，以及希望怎样改进，会很有帮助；分享案例时请隐去孩子的个人信息。

这个项目也是一个正在开发的家庭学习平台的一部分，平台与社区 Skill 会在实际使用中共同改进。
