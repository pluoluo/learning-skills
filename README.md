# Learning Skills

把孩子正在遇到的学习困难，变成一节可以动手探索的小课。

这里提供供各类 AI Agent 使用的学习 Skill。你在熟悉的 Agent 中描述一个问题，让它制作互动课程，带孩子通过操作、比较、尝试和反馈理解知识，再换一个例子看看能不能用上。

**[DEMO样例预览](https://b.pluoluo.top/learning-skills/)**。关于“周长与面积”的主题，推荐用平板横屏体验，也可以在电脑浏览器中试用，无需下载或安装 Skill。

![周长与面积互动小课预览](https://github.com/pluoluo/learning-skills/releases/download/v0.1.1/perimeter-area-preview.png)

## 它能帮你解决什么问题？

有时，孩子已经听过讲解，也记住了公式，遇到具体问题却仍然不知道怎么用。继续重复同一段解释，很难看出究竟卡在哪里。

这个 Skill 帮助家长和教育创作者围绕具体困难制作学习活动：

- **概念容易混淆**：例如分不清周长与面积，让孩子改变图形，分别观察边界长度和覆盖大小。
- **规则会背，换个情境就不会用**：例如知道近义词释义，却不会在句子中选择，便通过替换、比较和寻找语境依据来探索。
- **现成材料不贴合眼前的问题**：可以说明孩子已会什么、哪里停住、希望重点观察什么，据此制作范围合适的小课。
- **想让孩子主动尝试**：课程包含能改变对象或判断的操作，以及解释原因的反馈、按需提示和重试机会。

可以围绕数学、语文、英语中的具体问题创作。你不必先写完整教案，也不必准备一套教材；一个清楚的困惑就可以作为起点。


## 用它制作你的小课

制作和学习可以在不同设备上完成。家长通过熟悉的聊天或桌面 Agent 描述需求、预览和修改，孩子则优先使用平板横屏操作课件。

推荐的使用方式是：**家长向 Agent 提需求 → Agent 生成并交付课件 → 孩子在平板浏览器中动手探索。** Hermes 等常驻 Agent 可以利用已有部署环境，临时托管课件，方便家里的平板通过局域网链接打开。

| 使用方式 | 怎样使用成果 |
|---|---|
| Hermes 等常驻 Agent | 让 Agent 在已有环境中临时托管课件，把局域网链接交回聊天；孩子用同一网络中的平板浏览器打开 |
| 桌面 Agent | 家长预览、试用和修改；可交付课件文件，也可在环境支持时提供平板可访问的链接 |
| CLI 或其他开发工具 | 让 Agent 将课程保存到工作目录，并说明打开哪个文件 |

选择能加载 Skill、读写文件和运行脚本的 Agent 入口。构建工具需要 Agent 的执行环境提供 Node.js 20 或更高版本；环境检查和构建由 Agent 完成。具体预览与附件能力取决于你使用的应用和入口。普通聊天中上传说明文件是否足够，需要看该入口实际提供的工具。

1. **[下载完整 Skill](https://github.com/pluoluo/learning-skills/releases/download/v0.1.3/interactive-topic-lesson-v0.1.3.zip)**，解压并保留整个 `interactive-topic-lesson` 文件夹。
2. 按你的 Agent 的安装方式，将该文件夹放入技能目录。Hermes 用户可放到 `~/.hermes/skills/interactive-topic-lesson`，在新会话中使用 `/interactive-topic-lesson`。
3. 按下面的方式描述需求，并告诉 Agent 孩子准备在平板上使用；需要局域网链接时一并说明。

### 用平板打开常驻 Agent 生成的课件

可以直接对 Hermes 说：

> 请把这节课临时部署在你运行的机器上，给我一个同一局域网里的平板可以打开的地址。请说明地址多久有效、怎样停止服务，并保留课件文件方便以后再用。

Agent 负责构建课件、启动临时服务并检查地址。平板与服务所在机器需要处于可互通的局域网；如果 Hermes 运行在 NAS 或容器中，可以使用已有端口映射或部署方式。链接通常只在服务运行期间有效。

部署方式由 Agent 根据自己的环境选择，Skill 只约定交付边界：提供平板可访问的地址，只发布本次课件，说明服务的有效时间和停止方法，并保留可再次使用的课程文件。需要离线使用时，可以让 Agent 另外提供 HTML 或 ZIP 文件。

## 告诉 Agent 哪些信息？

**最省事的开始方式：说清“给谁学、学什么、想解决什么问题”。** 如果不知道卡在哪里，直接说“不确定，想先探索一下”就可以。

| 信息 | 怎么说 | 什么时候补充 |
|---|---|---|
| **学习主题** | “周长与面积”“比较分数大小”“在语境中选近义词” | 创建课程需要明确主题 |
| **年级或已有基础** | “四年级，会算长方形周长和面积” | 建议一开始就说，帮助调整语言和难度 |
| **具体困惑或学习目的** | “会套公式，但题目换成围栏和草地就分不清” | 建议一开始就说；未知时说明想探索或整理什么 |
| 一个具体例子 | 一道错题、孩子的原话、教材片段或图片 | 希望课程更贴合实际困难时提供；也可以只用文字描述 |
| 希望看到的变化 | “能先判断量的是边界还是覆盖大小，再选计算方法” | 想把成果做得更贴合目标时补充 |
| 使用偏好 | “一次约10分钟”“解释短一点”“主要用点选”“不使用声音” | 有时间、设备或操作要求时补充 |

教案、互动设计、按需提示、内容检查和文件打包交给 Agent。信息不足时，它应先问影响课程的关键问题，并说明采用了哪些假设。

### 可以直接复制的需求

**先做一节试试：**

> 使用 interactive-topic-lesson，给【年级或基础】的孩子做一节关于【主题】的互动小课。现在的困惑是【具体表现；不确定也可以说明】。孩子主要在平板上操作。请提供课件；如果你的环境可以临时托管，请给我同一局域网中能打开的链接，并说明有效时间和停止方法。

**围绕一个实际困难制作：**

> 使用 interactive-topic-lesson。孩子四年级，会算长方形周长和面积，但看到“围一圈”和“铺草地”时经常选错公式。请围绕这两种量的区别，做一节约10分钟的小课，让他能改变图形、观察反馈，最后用新例子判断该量什么。主要使用点选，解释简短，保留按需提示。请在当前会话提供课程文件。

**没有错题，只想理解一个问题：**

> 使用 interactive-topic-lesson，给已经接触过分数的三年级孩子做一节小课：同样大小的纸条，为什么1/2比1/3大？我们还不确定他卡在哪里，希望先通过等分和比较探索原因，再换一个例子试试。请提供可以打开的课程。

### 怎样更容易做出合适的小课？

- **把宽泛评价换成具体表现。** 比起“数学不好”，“会算角度加减，但在多线图里找不到已知条件”更能帮助 Agent 选择活动。
- **聚焦一个近期问题。** 比如先研究“同样长的围栏能不能围出不同面积”，再逐步扩展到更大的专题。
- **说清已经会什么。** 这样课程可以把篇幅用在需要探索的关系上，并按需提供基础帮助。
- **用试用结果继续修改。** 告诉 Agent “哪个操作不清楚”“哪段解释太长”“哪个新例子仍然不会做”，可以同时附上截图。它应沿用当前课程修改，并保留可继续编辑的内容。

## 你会得到什么？

最主要的成果是一节可以在平板浏览器中操作的互动课程。常驻 Agent 可以交付**临时局域网链接**，也可以提供 **`index.html` 文件**供下载保存。孩子打开后就能操作、查看反馈并完成本次练习。

同时会保留可编辑的课程内容，方便继续调整、重新生成或交给学习应用使用。课程不依赖本项目的学习平台账号，当前独立版的操作和选择保留在本次页面中。

AI 生成后，建议先亲自操作一遍，核对知识、图示和答案是否符合预期。孩子在一节课里的表现，可以帮助你发现下一步值得继续探索的问题。

## 持续更新

我会持续维护这个项目，根据真实使用反馈改进教学设计、操作体验和生成质量，补充更丰富的学科样例，并逐步分享更多实用的学习 Skill。

如果你遇到不好理解的反馈、无法操作的内容，或某个学习问题始终没有被解决，欢迎通过 **[Issues](https://github.com/pluoluo/learning-skills/issues)** 告诉我。描述你想解决的问题、实际发生了什么，以及希望怎样改进，会很有帮助；分享案例时请隐去孩子的个人信息。

这个项目也是一个正在开发的家庭学习平台的一部分，平台与社区 Skill 会在实际使用中共同改进。
