# Learning Skills

把孩子的具体学习困难，交给 AI Agent 做成一节能动手探索的互动小课。

[DEMO 样例预览](https://b.pluoluo.top/learning-skills/)：以“周长与面积”为例，推荐平板横屏体验，也可以电脑浏览器打开，无需下载或安装 Skill。

![周长与面积互动小课预览](https://github.com/pluoluo/learning-skills/releases/download/v0.1.4/perimeter-area-preview.png)

## 这是什么？

这不是题库，也不是现成课程合集，而是一个给 AI Agent 用的学习 Skill。

你不需要先写教案，也不用准备一套教材。只要把“孩子哪里卡住了”告诉 Agent，它就能围绕这个具体问题，生成一节可以在浏览器里操作的小课：孩子可以改变图形、比较选项、尝试判断，看到反馈，按需看提示，再换一个例子试试。

课程可以围绕数学、语文、英语里的具体问题制作。一个清楚的困惑，就可以作为起点。

## 它解决什么问题？

适合这些场景：

- **概念容易混淆**：比如分不清周长和面积。让孩子改变图形，分别观察“边界长度”和“覆盖大小”。
- **规则会背，换个情境就不会用**：比如知道近义词释义，却不会在句子里选。通过替换、比较和找语境依据来探索。
- **现成材料不贴合眼前问题**：说明孩子已经会什么、停在哪里、想重点观察什么，让课程范围更合适。
- **想让孩子主动尝试**：课程里有可操作的对象、解释原因的反馈、按需提示和重试机会。

比起“数学不好”，更具体地说“会算长方形周长和面积，但看到‘围一圈’和‘铺草地’就选错公式”，Agent 更容易做出合适的小课。

## 怎么用？

推荐流程很简单：

**家长向 Agent 提需求 → Agent 生成并交付课件 → 孩子在平板浏览器里动手探索。**

### 1. 让 Agent 安装 Skill

不用自己下载压缩包、解压、找目录。把 Skill 链接发给你的 Agent，让它自己安装。

完整 Skill 下载地址：

https://github.com/pluoluo/learning-skills/releases/download/v0.1.4/interactive-topic-lesson-v0.1.4.zip

可以直接对 Agent 说：

```
请安装这个 skill：https://github.com/pluoluo/learning-skills。装好后告诉我怎么在新会话里调用它，以及需要我补充哪些信息。
```

你的 Agent 需要能加载 Skill、读写文件、运行脚本。构建工具需要 Node.js 20 或更高版本，环境检查和构建交给 Agent 完成即可。

如果你用的是 Hermes，可以让它把 Skill 放到 `~/.hermes/skills/interactive-topic-lesson`，之后在新会话里使用 `/interactive-topic-lesson`。其他 Agent 按它自己的技能安装方式处理。

### 2. 告诉 Agent：给谁学、学什么、想解决什么

最少说清这三件事就能开始：

- 给几年级或什么基础的孩子学
- 学什么主题
- 现在卡在哪里；不确定也可以说“想先探索一下”

还可以补充：一道错题、孩子的原话、教材片段、希望看到的变化，以及使用偏好，比如“一次约 10 分钟”“解释短一点”“主要用点选”“不要声音”。

可以直接复制这段：

> 使用 interactive-topic-lesson，给四年级、会算长方形周长和面积的孩子做一节互动小课。他看到“围一圈”和“铺草地”时经常选错公式。请围绕这两种量的区别，做一节约 10 分钟的小课，让他能改变图形、观察反馈，最后用新例子判断该量什么。主要使用点选，解释简短，保留按需提示。孩子主要在平板上操作。请提供课件；如果你的环境可以临时托管，请给我同一局域网中平板能打开的链接，并说明有效时间和停止方法。

如果信息不够，Agent 应该先问影响课程的关键问题，并说明它采用了哪些假设。

### 3. 让孩子在平板上打开

常驻 Agent，比如 Hermes，可以利用已有环境临时托管课件，给你一个同一局域网内平板能打开的链接。它应该说明链接多久有效、怎么停止服务，并保留课件文件方便以后再用。

桌面 Agent 或 CLI 也可以直接生成 `index.html` 或课程文件，让你预览、修改和保存。

孩子优先用平板横屏操作。AI 生成后，建议家长先自己操作一遍，核对知识、图示和答案是否符合预期。

## 你会得到什么？

主要是一节能在平板浏览器里操作的互动课程，形式可以是临时局域网链接，也可以是 `index.html` 文件。

同时会保留可编辑的课程内容，方便继续修改、重新生成或交给学习应用使用。课程不依赖本项目的学习平台账号，当前独立版的操作和选择保留在本次页面中。

如果试用后发现“这个操作不清楚”“这段解释太长”“换了个例子还是不会”，把具体表现或截图告诉 Agent，让它沿用当前课程继续改。

## 反馈与许可

遇到不好理解的反馈、无法操作的内容，或某个学习问题始终没被解决，欢迎到 [Issues](https://github.com/pluoluo/learning-skills/issues) 反馈。描述你想解决的问题、实际发生了什么、希望怎样改进即可；分享案例时请隐去孩子的个人信息。
